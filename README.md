# 🎬 Netflix Data Analytics & Exploratory Data Analysis (EDA)



---

# 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Netflix dataset to uncover valuable insights about content distribution, genres, ratings, release trends, and global streaming patterns.

The project was developed using Python and Jupyter Notebook with the goal of transforming raw entertainment data into meaningful business insights through data cleaning, visualization, and storytelling.

---

# 🎯 Objectives

* Analyze Netflix content trends
* Understand movie vs TV show distribution
* Explore genre popularity
* Identify top contributing countries
* Analyze ratings and release patterns
* Perform data cleaning and preprocessing
* Create visual storytelling using Python

---

# 📈 Key Insights

* Movies dominate Netflix content compared to TV shows.
* Drama and Comedy are the most common genres.
* The United States contributes the highest number of titles.
* Netflix content increased significantly after 2015.
* TV-MA is the most common rating category.
